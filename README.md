## Análise Comparativa Pessoal

Nesta atividade, o que mais me chamou a atenção foi a diferença de "limpeza" visual entre as linguagens. No primeiro exercício, o Python se destacou muito; enquanto em Java precisei de várias linhas para a mesma lógica, no Python o código ficou super conciso. Já no Haskell, a mudança de lógica para algo funcional foi o maior desafio, pois foge totalmente do que estou acostumado no dia a dia.

Na parte de seleção múltipla, achei o Ruby fantástico. Poder usar intervalos como '6..8' facilita muito a vida e evita aquela repetição chata de 'case' que vi no C. Por outro lado, o exercício de retirar 'gotos' e 'breaks' me fez perceber como esses comandos, apesar de criticados, às vezes deixam o código mais direto. Sem eles, tive que criar variáveis de controle (flags) que deixaram o código um pouco mais "poluído", mas certamente mais seguro e fácil de debugar.
